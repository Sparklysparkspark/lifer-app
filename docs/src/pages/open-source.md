# Free and open source

Lifer is free to use, and all of its code is public under the AGPL-3.0 license.

## What the license allows

You can use Lifer for anything, read how it works, change it and share it. If you share a changed version, or run one for other people over a network, you share its source code under the same license. The full terms are in the [LICENSE](https://github.com/Sparklysparkspark/lifer-app/blob/main/LICENSE) file.

## Where the code is

Everything is in [one repository on GitHub](https://github.com/Sparklysparkspark/lifer-app): the desktop app, the server, the Lightroom Classic plugin and the pipeline that builds the species catalog. Installers are built from it by public workflows, and [Code signing](/code-signing) explains how each one is signed.

## Data and photos

The species catalog comes from open data, and every reference photo belongs to its photographer under the license they chose. Each source keeps its own terms, which [Credits](/credits) lists, including what to leave out if you reuse the data commercially.
